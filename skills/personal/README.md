# Personal

Skills tied to my own internal/company tooling (Feishu Project, Lanhu, lark-cli) or to maintaining this repo's own personal-skill workflow. Actively used, just not publishable through the public plugin: an installer without that internal tooling couldn't run them. Not promoted (no top-level `README.md` entry, no `plugin.json` entry, no `docs/` page), but linked by `scripts/link-skills.sh` like a promoted bucket, since reuse across my own projects is the point.

- **[brief-feishu-ticket](./brief-feishu-ticket/SKILL.md)**: Brief one Feishu Project issue (via the external `meegle` skill) into a standalone summary the rest of the session can work from.
- **[promote-project-skill](./promote-project-skill/SKILL.md)**: Move a project-local skill, once validated in daily work, into this repo so it's shared and versioned here.
- **[requirement-intake](./requirement-intake/SKILL.md)**: Intake a requirement from Lanhu MCP prototypes and a Feishu wiki PRD before grilling or implementing.
- **[verify-skill-setup](./verify-skill-setup/SKILL.md)**: Check, install, and live-verify a skill's declared prerequisites, right after it lands in a new project.
